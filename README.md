# Teste Prático - Indústria

Projeto em Java para gerenciar uma lista de funcionários de uma indústria.

## Classes

- Pessoa: nome e data de nascimento
- Funcionario: herda de Pessoa e tem salário e função
- Principal: executa as ações pedidas no teste

## Como rodar

Abrir o projeto em uma IDE (IntelliJ, Eclipse, NetBeans) e executar a classe Principal.

## O que foi feito

Itens 3.1 a 3.12 do enunciado (o item 3.7 não existe no texto do teste):

- Inserir e remover funcionários
- Imprimir com data em dd/mm/aaaa e valores no padrão brasileiro
- Aumento de 10% nos salários
- Agrupar por função usando `Map`
- Aniversariantes dos meses 10 e 12
- Funcionário mais velho
- Ordem alfabética
- Total dos salários
- Quantidade de salários mínimos de cada funcionário
